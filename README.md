# Mission Control

A touchscreen information console for the ham shack.

## Vision

A custom ESP32-S3 dashboard combining:

- Local and UTC clocks
- Weather
- Solar Conditions
- Satellite tracking
- Flight tracking
- POTA Spots
- Live Spots
## Hardware

Planned:
- ELECROW CrowPanel ESP32-S3 7" display

## Software

- PlatformIO
- Arduino framework
- LVGL graphics
- Wi-Fi
- Modular services architecture

## Status

Project initialized.
