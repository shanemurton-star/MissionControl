# Mission Control

A touchscreen information console for the ham shack.

## Vision

A custom ESP32-S3 dashboard combining:

- Local and UTC clocks
- Weather and radar
- Air quality
- Space weather
- Satellite tracking
- Flight tracking
- IC-7300 integration
- Microsoft 365 calendar
- Ham radio tools

## Hardware

Planned:
- ELECROW CrowPanel ESP32-S3 7" display

## Software

- PlatformIO
- Arduino framework
- LVGL graphics
- Wi-Fi
- Modular services architecture
